# 网页调色盘 <-> 佳明表盘 主题短码通信协议 (Theme Code Spec)

为了在 **Cloudflare Pages 静态网页调色盘** 与 **Garmin Connect 手机设置项** 之间实现零服务器、离线秒级同步，定义如下紧凑型字符串协议。

## 1. 短码格式定义

```text
F{字体ID}-B{背景模式}-A{弧线模式}-{背景HEX}-{小时HEX}-{分钟HEX}-{秒钟HEX}-{简笔线条HEX}-{数据主色HEX}-{数据高亮HEX}
```

### 示例短码（4 套默认日本传统色主题）
- **昼·壱 (白练 · 茜素)**：`F2-B0-A0-F3F3F2-1C1C1C-B7282E-787878-9EA1A3-524E4D-B7282E` *(MIP版: `F2-B0-A0-FFFFFF-000000-AA0000-555555-AAAAAA-555555-AA0000`)*
- **昼·弐 (鸟之子 · 青磁)**：`F1-B0-A0-EFEACC-2B373B-69B0AC-828282-BC9F77-494A41-69B0AC` *(MIP版: `F1-B0-A0-FFFFAA-000055-00AAAA-555555-AA5500-555500-00AA55`)*
- **夜·壱 (胜色 · 樱月)**：`F3-B0-A0-0B1013-F7FCFE-FEDFE1-8899A0-566C73-ADADAD-F596AA` *(MIP版: `F3-B0-A0-000000-FFFFFF-FFAAAA-5555AA-5555AA-AAAAAA-FF55AA`)*
- **夜·弐 (消炭 · 琥珀宵)**：`F5-B6-A0-0C0C0C-F4DDA5-CA7A2C-9E9478-5A5359-9E9478-E2943B` *(MIP版: `F5-B6-A0-000000-FFFFAA-FF5500-AA5500-555555-AAAA55-FFAA00`)*

## 2. 字段枚举说明

| 字段位 | 含义 | 取值范围 | 说明 |
| :--- | :--- | :--- | :--- |
| `F{1-5}` | 时间主字体 | `F1`~`F5` | `F1`: iPhone裂开字体<br>`F2`: 宋体/明朝体(衬线)<br>`F3`: 硬派黑体(无衬线)<br>`F4`: 电子表八段数码管<br>`F5`: 复古辉光管 |
| `B{0-6}` | 日系简笔背景 | `B0`~`B6` | `B0`: 自动跟随实时天气与日出日落<br>`B1`: 晴 · 远山日轮(富士山线+日轮)<br>`B2`: 云 · 浮世流云(日式源氏霞云线)<br>`B3`: 阴/雾 · 水墨层峦(双层山脊+晨雾线)<br>`B4`: 雨 · 细雨涟漪(斜雨丝+水波纹)<br>`B5`: 雪 · 雪峰寒星(覆雪山尖+几何雪花)<br>`B6`: 夜 · 弦月眠猫(弯月星辰+趴坡小猫剪影) |
| `A{0-2}` | 左右边缘进度弧 | `A0`~`A2` | `A0`: 关闭（推荐，最具日式留白呼吸感）<br>`A1`: 极简细弧线 (2px)<br>`A2`: Enduro 分段胶囊刻度条 |
| `HEX x 7` | 7个部位的16进制和色 | `000000`~`FFFFFF` | 依次为：表盘和纸底色、小时数字、分钟数字、秒钟数字、简笔画背景线条、身体数据文字、朱印/图标高亮色 |

## 3. MIP 64色自动吸附规则（反射屏机型专用）
佳明 MIP 反射屏（如 Fenix 7 / Forerunner 255 / Enduro 2）每个 RGB 通道仅支持 2-bit（4级亮度）：
- 合法通道值：`00` (0), `55` (85), `AA` (170), `FF` (255)
- 网页调色盘在勾选 **“MIP 反射屏 64色模式”** 时，会自动将用户选择的任意 RGB 颜色通过最近邻算法量化到 `4 x 4 x 4 = 64` 色标准网格，保证网页预览效果与手表真机 100% 零色差。
