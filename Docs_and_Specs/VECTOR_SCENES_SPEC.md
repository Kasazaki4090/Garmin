# Komorebi 6 套日系简笔画矢量坐标规范 (VECTOR_SCENES_SPEC.md)

> **设计定位**：本规范为 `MinimalBgDrawer.mc`（表盘端）与 `Cloudflare_page/app.js`（网页端）提供 **像素级 1:1 对应的归一化几何坐标表**。
> **核心原则**：任何 AI Agent 编写背景代码时，**严禁自行臆造坐标或偷懒只画一个小圆圈**，必须严格按本规范给定的归一化坐标 `(xRatio * w, yRatio * h)` 绘制全部图层元素！

## 一、 全局构图与视觉避让原则（Composition & Safe Zones）

为了既展现日本传统浮世绘/水墨手账的意境，又**绝不干扰中央大时间和上下数据区的可读性**，所有简笔画由 **3 个标准图层** 组合而成：

```text
         ╭───────────────────────╮
      ╭──┤   [Top Data: y=0.14]  ├──╮
    ╭─╯  ╰───────────────────────╯  ╰─╮
   ╭╯  ↖ 圆相禅圈 (Ensō)      [右上远景] ╰╮  <-- Layer B: 右上天象区 (x: 0.68~0.84, y: 0.20~0.28)
  ╭╯     r = 0.44 * W         (日/月/雨/雪)╰╮      (避开 y=0.14 气温，位于分钟上方留白处)
  │   ┌───────────────────────────┐   │
  │   │                           │   │
  │   │     11 : 21 / 34          │   │  <-- 中央时间区 (y: 0.31~0.62) 内部保持纯净！
  │   │                           │   │
  ╰╮  └───────────────────────────┘  ╭╯
   ╰╮  [Layer C: 底部山川/流云/眠猫]   ╭╯  <-- Layer C: 黄金地景带 (x: 0.16~0.84, y: 0.63~0.71)
    ╰─╮  ╭───────────────────────╮  ╭─╯      (完美嵌在时间底部 0.62 与数据顶排 0.76 之间！)
      ╰──┤ [Bottom Data: y=0.77] ├──╯
         ╰───────────────────────╯
```

### Layer A：圆相禅圈（Ensō —— 所有模式共用的外框气韵）
- **形态**：一笔挥就的日式禅意圆环，环抱整个表盘内缘，在**左下角（7点~8点钟方向）**留出呼吸缺口，并在缺口处带一笔双线飞白质感。
- **精确参数**：
  1. 主圆弧：圆心 `(0.50, 0.50)`，半径 `r = 0.445 * min(w, h)`，线宽 `2px`，方向 `Graphics.ARC_CLOCKWISE`，起点 `200°`（约 8 点半），终点 `240°`（约 7 点钟）—— 顺时针扫过 `320°`。
  2. 笔锋飞白（副弧）：同圆心，半径 `r - 3px`，线宽 `1px`，方向 `Graphics.ARC_CLOCKWISE`，起点 `185°`，终点 `220°`（在起笔处形成毛笔分叉飞白效果）。

### 模式自动映射规则（`B0` 自动模式）
当主题短码指定 `B0` 时，`MinimalBgDrawer` 必须根据当前时间与 `Weather.getCurrentConditions()` 自动选择 `B1 ~ B6`（**严禁直接落入单一静态默认分支**）：
1. **夜间优先**：若当前小时 `hour >= 19 || hour < 6`，直接切换为 **`B6`（夜 · 弦月眠猫）**。
2. **日间按天气映射**：
   - 雨/雷雨/阵雨 → **`B4`（雨 · 细雨涟漪）**
   - 雪/雨夹雪/冰雹 → **`B5`（雪 · 雪峰寒星）**
   - 雾/霾/阴天/大风 → **`B3`（阴/雾 · 水墨层峦）**
   - 多云/少云 → **`B2`（云 · 浮世流云）**
   - 晴朗/无天气数据 → **`B1`（晴 · 远山日轮）**

## 二、 6 套日系简笔画（`B1` ~ `B6`）精确归一化坐标表

> 约定：所有坐标 `(x, y)` 均为 `0.000 ~ 1.000` 的归一化比例，代码中实际像素为 `(w * x).toNumber()` 和 `(h * y).toNumber()`。
> 颜色参数：主线条使用 `theme.colorBgLines`（淡墨/素鼠/蓝鼠），点缀元素（如朱印太阳、暖黄弦月）可使用 `theme.colorAccent` 或 `theme.colorBgLines`。
